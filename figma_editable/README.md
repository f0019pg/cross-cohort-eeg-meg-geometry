# Editable supplementary figures

These SVG files are the editable source versions of Supplementary Figs. 1, 3, 4, 8 and 11. Import or drag each SVG into Figma. Text is stored as live SVG text rather than outlined paths, and plot elements remain separate vector objects.

- `Supplementary_Figure_1_editable.svg`
- `Supplementary_Figure_3_editable.svg`
- `Supplementary_Figure_4_editable.svg`
- `Supplementary_Figure_8_editable.svg`
- `Supplementary_Figure_11_editable.svg`

The manuscript embeds high-resolution PNG exports. After editing in Figma, export at the original aspect ratio and at least 600 dpi for print use.

Font substitution can occur if Arial is unavailable in the Figma environment. Check symbols such as rho, delta and minus signs after import.
